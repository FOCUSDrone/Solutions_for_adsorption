# 压力传感器
1. 压力传感器要在SCL和SDA上分别接一个上拉电阻电阻，否则不能正常工作。
2. 压力传感器有休眠模式与组合模式。经测量组合模式（单次模式）误差较大，建议用休眠模式（循环模式）。
3. 这个压力传感器引脚很脆容易断，轻拿轻放。
